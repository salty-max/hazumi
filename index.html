Matter

A creative-coding library in the p5.js tradition, rebuilt on a typed core and a retained command buffer — with WebGL2 as the default renderer rather than the fallback.

A sketch

import { sketch } from 'matter';
import { webgl2 } from 'matter/backends/webgl2';

sketch({ backend: webgl2(), width: 600, height: 600 }, () => {
  return ({ background, circle, fill, width, height, t }) => {
    background('oklch(0.15 0.02 260)');
    fill('oklch(0.72 0.18 250)');
    circle(width / 2, height / 2, 200 + Math.sin(t) * 80);
  };
});

The context is destructured in the draw callback rather than injected onto window. That keeps almost all of p5 global mode's terseness while staying fully typed, and because the same object is mutated in place, reading t or width costs nothing per frame.

Why it exists

p5.js is excellent, and this is not a replacement for it. But its WebGL mode is its weakest area — sketches that need real GPU throughput tend to leave for Three.js and lose the friendly API on the way out. Matter aims at that gap.

100k shapes10.0 ms per frame, one draw call — 60% of the 60fps budget
AllocationZero in steady state: 0.0 kB heap delta over 200 frames
BackendsWebGL2, Canvas2D, SVG and a headless recorder, from one command stream
Agreement12 scenes verified pixel-by-pixel across backends
ColourOKLCH throughout, so blends stay perceptually even
RandomnessSeeded by default — a sketch renders identically every run

Not there yet

Bezier paths, images and pixel access, and a WebGPU backend. Text renders from a runtime SDF rather than MSDF, so corners soften well above the atlas resolution. Not published to npm.
